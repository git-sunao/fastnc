# Tutorials

This directory is reserved for concise, polished examples of the supported
public `fastnc` API. Exploratory calculations, implementation validation, and
historical notebooks belong under `dev/`, grouped by topic.

A tutorial uses only public interfaces, explains one stable workflow, and
avoids importing helper scripts or legacy snapshots from `dev/`. Notebook
outputs are kept empty in Git. Sphinx renders these notebooks through the
lightweight links in `docs/tutorials/`; do not duplicate their contents there.
